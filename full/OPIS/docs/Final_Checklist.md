# Final Submission Checklist (Quality Gates)

## Evidence discipline
- [ ] Every recommendation has linked evidence (file paths in `evidence/` + notes in `research/`)
- [ ] No fabricated observations

## Recommendation quality
- [ ] Each recommendation includes Observation, Root Cause, Engineering/User/Business Impact, Solution, Steps, Complexity, Trade-offs, Priority
- [ ] Prioritized by user impact vs engineering effort

## Writing quality
- [ ] Concise and actionable technical explanations
- [ ] No AI clichés
- [ ] Consistent formatting, grammar checked
- [ ] Fits one-page constraint expectations

## Cross-check
- [ ] Android + Website are both covered
- [ ] Auth, navigation, AI features, performance, security, accessibility, edge cases are evaluated
