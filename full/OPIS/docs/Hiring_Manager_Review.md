# Hiring Manager Review (Template)

Use this as an internal doc to self-check depth and hiring-panel readiness.

## A) Technical depth
- API design quality
- AuthN/AuthZ correctness
- Error handling
- Observability (logging/monitoring)
- Security posture (validation, token lifecycle)
- Scalability/reliability thinking

## B) Product engineering judgment
- Activation friction identification
- Missing workflows
- Retention opportunities
- Feedback loops/automation potential

## C) Evidence discipline
- No fabricated observations
- Every recommendation has linked evidence (file path + screenshot/recording reference)

## D) Communication quality
- Clear executive framing
- Actionable engineering steps
- Prioritized trade-offs

## Checklist status
- [ ] Passes evidence gate
- [ ] Passes recommendation quality gate
- [ ] Meets “one-page limit” expectations for each submission
