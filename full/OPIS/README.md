# Omnimise Product Intelligence Suite (OPIS)

Engineering Product Review & Full Stack Analysis Framework

## What this repository contains

OPIS is a repeatable, evidence-first framework to evaluate Omnimise (Android app + website) from multiple engineering and product perspectives.

### Outputs

- **Technical Product Review** (structured engineering recommendations)
- **Product & Engineering Thinking** (workflow redesign + product vision)
- **Evidence Repository** (screenshots, notes, bugs, performance measurements)

## How to use

1. Create an **evidence-first** log while exploring the Android app and website.
2. Translate observations into recommendations using the provided templates.
3. Ensure every recommendation has corresponding evidence.
4. Export final documents into `final/`.

## Repository structure

See `OPIS/docs/` and `OPIS/evidence/` for templates and working documents.
